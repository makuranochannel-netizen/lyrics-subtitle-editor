# 歌詞字幕エディタ

動画を再生しながら **Shift キーで歌詞の表示タイミングを1行ずつ記録**し、字幕を焼き込んだ MP4 を書き出すブラウザアプリです。
インストール・ビルド不要（Python 3 の簡易サーバーだけで動作）。

## 起動方法

```bash
cd lyrics-subtitle-editor
./start.command        # または: python3 -m http.server 5173 --bind 127.0.0.1
```

ブラウザで <http://localhost:5173/> を開きます（**Google Chrome / Microsoft Edge 推奨**。WebCodecs と File System Access API を使用）。
Finder から `start.command` をダブルクリックしても起動できます。

> 保存データ（歌詞・プロジェクト）はブラウザの IndexedDB に `localhost:5173` 単位で保存されます。ポート番号を変えると別の保存領域になります。

## iPhone で使う

iPhone の Safari（iOS 17 以降推奨）でも、記録から字幕入り MP4 の書き出しまでできます。動画処理には https の URL が必要なため、ネットに公開して使います（手順は下の「ネットに公開する（GitHub Pages）」）。

- **記録**：「● 記録開始」を押すと、下に大きなピンクのボタンが出ます。歌詞を出したい瞬間にタップすると記録されます（指が触れた瞬間の時刻で記録）。間違えたら「↶ 取り消し」。
- **動画を開く**：写真ライブラリやファイルアプリから選べます。
- **保存**：書き出し完了後「📱 写真に保存 / 共有」→「ビデオを保存」で写真アプリに保存できます。
- **ホーム画面に追加**：Safari の共有ボタン →「ホーム画面に追加」。全画面のアプリとして使え、オフラインでも起動します。Safari で開いたまま使うと、しばらく使わない場合に保存データが消えることがあるため、ホーム画面への追加をおすすめします。
- 歌詞・プロジェクト・動画は iPhone の中だけに保存され、サーバーには送られません。
- iPhone では使えないもの：キーボードショートカット、「Mac のすべてのフォントを表示」、音声が AAC 以外の動画の書き出し（iPhone で撮った動画は AAC なので問題ありません）。

## ネットに公開する（GitHub Pages）

1. <https://github.com> でアカウントを作成してログイン
2. 右上「＋」→「New repository」→ 名前（例：`lyrics-subtitle-editor`）、**Public** を選んで「Create repository」
3. 作成後の画面の「uploading an existing file」をクリック
4. Finder でこのフォルダ（`lyrics-subtitle-editor`）を開き、**中身をすべて選択**（⌘A）してブラウザにドラッグ＆ドロップ →「Commit changes」
   - `index.html` がリポジトリのいちばん上に来るようにしてください（フォルダごとではなく中身をドロップ）
5. リポジトリの「Settings」→ 左の「Pages」→ Branch を `main`・`/ (root)` にして「Save」
6. 1〜2 分後、同じ画面に `https://ユーザー名.github.io/lyrics-subtitle-editor/` と表示されます。これを iPhone の Safari で開きます

更新するとき：変更したファイルを同じ手順（Add file → Upload files）でアップロードすると、数分後に反映されます。

## 使い方

1. **歌詞を登録**：左パネル上の「📚 歌詞ライブラリ ↗」で**歌詞ライブラリが別タブ**で開きます（iPhone では同じ画面で開き、「← エディタ」で戻ります）。「＋ 新しい歌詞」で楽曲名と歌詞を1行1字幕で入力して「保存してこのプロジェクトで使う」。歌詞が空のときは「歌詞を入力」からその場で入力することもできます。
   - 左パネルの「«」で**歌詞・タイミングを縮小表示**できます（PC は細い帯、スマホは見出しだけ）。帯をクリックすると元に戻ります。
   - **歌詞の修正・分割・削除はタイムライン（画面下）で**行います。ブロックをクリック（タップ）して選ぶと、タイムライン上部に **✏️ 修正**・**✂ カーソル位置で分割**・**🗑 削除** が出ます。
     - 分割：ブロックの分けたい時刻をクリック（赤い線がそこへ移動）→「✂ カーソル位置で分割」。同じ歌詞のブロックが、赤い線の位置で2つに分かれます（例：「君が好き」→「君が好き」「君が好き」）。
   - 左の歌詞一覧で行を選ぶと、タイミングの微調整・**⤓ 次の行と結合**・**＋ 下に行を追加**・**↑↓ 並べ替え** ができます。文字の上をダブルクリックでも修正できます。
2. **動画を開く**：「動画を開く」またはプレビューにドラッグ＆ドロップ（MP4 / MOV。iPhone 縦動画・横動画・正方形など）。
3. **タイミングを記録**：「● 記録開始」ボタン（または `R` キー）で**記録モード**にすると再生が始まります。歌詞が出るべき瞬間に `Shift` を押すだけで記録されます（記録モード中はカーソルが入力欄にあっても記録されます。`Esc` か「■ 記録モード終了」で終了、最後の行を記録すると自動終了）。押した時点の**動画の再生時間**が記録され、次の行へ進みます。前の行の終了時刻は自動で「次の行の開始」になり、最後の行は動画の最後まで表示されます。
   - 間奏など歌詞を出さない部分では「**⏹ 歌詞を消す**」（キーボードは `E`）を押すと、その時刻で歌詞が消え、次の歌詞を記録すると再び表示されます。
   - **記録を始める位置**は、左の歌詞一覧の各行の「● ここから」で指定できます（記録済みの行も選べ、記録すると上書きされます。記録済みの行を選ぶと再生位置がその2秒前に戻ります）。今の記録位置の行には「● 記録位置」と表示されます。
   - 「⏮」（再生バー）／「⏮ 0:00」（タイムライン）で動画の最初に戻れます。
4. **修正**：押し間違えたら `⌘/Ctrl+Z`。行をクリックすると開始/終了の微調整（±0.01 / ±0.1 秒、直接入力、現在位置）ができます。タイムラインのブロックはドラッグで移動・端で長さ調整。
5. **デザイン**：動画のすぐ下の「字幕デザイン」（見出しクリックで開閉）でいちばん上の「↑ 大きく / ↓ 小さく」ボタンで字幕サイズを1段階ずつ変更できます。ほかにもフォント・サイズ・色・縁取り・影・背景・位置・横書き/縦書き・アニメーションを設定（プレビューに即時反映）。プリセット（白文字＋黒縁など）はセクションの下の方にあり、1回押すとオン、もう1回押すとオフ（押す前の設定に戻る）。フォントは Mac / Pages と同じフォントから選べます。游ゴシック・筑紫丸ゴ・凸版文久・クレーなど「未ダウンロード」のものは Font Book.app でダウンロードすると使えます。「Mac のすべてのフォントを表示…」で自分で入れたフォントも選べます。
6. **書き出し**：「MP4 書き出し」。元動画と同じ解像度・アスペクト比で字幕を焼き込みます。

### キーボードショートカット

| キー | 動作 |
|---|---|
| `R` / `Esc` | 記録モードの開始・終了 / 終了 |
| `Shift`（左右どちらでも） | 記録モード中：現在の再生時間を記録して次の歌詞へ（記録キーは右パネルで Enter / J / F / Tab にも変更可） |
| `Space` | 再生 / 一時停止 |
| `←` / `→` | 指定秒数戻る / 進む（既定 2 秒） |
| `,` / `.` | 1 フレーム（1/30 秒）戻る / 進む |
| `E` | 表示中の字幕をこの時刻で消す（間奏など） |
| `⌘/Ctrl+Z`、`⌘/Ctrl+Shift+Z` | 取り消し / やり直し |
| `⌘/Ctrl+S` | 保存（変更は自動保存もされます） |

文字入力欄にフォーカスがある間はショートカットは無効です。

## 保存について

| データ | 保存先 |
|---|---|
| 歌詞ライブラリ（楽曲名・行） | IndexedDB `lyrics` |
| プロジェクト（歌詞のコピー、タイミング、デザイン、編集状態、動画の情報） | IndexedDB `projects` |
| 動画ファイル | 既定では保存しない（ファイル名・サイズ・長さ・解像度のみ記録） |

- 歌詞（行ID・本文・順番）とタイミング（行ID → 開始/終了）は**別々に保持**しています。歌詞を保存しただけではタイミングは確定せず、並べ替えや文言修正をしてもタイミングは行に紐づいたまま維持されます。
- **動画の再読み込み**：プロジェクトを開くと、Chrome では前回選んだファイルへの「アクセスを許可して開く」ボタンが出ます。それ以外の場合は同じ動画ファイルを再選択してください（名前・サイズが異なると警告します）。
- 右パネル「動画をブラウザ内にも保存」をオンにすると動画自体を IndexedDB に保存し、次回から自動で読み込みます（ブラウザのストレージ容量を消費します）。
- プロジェクトメニューから JSON での書き出し／読み込み、SRT・ASS 字幕ファイルの書き出しもできます。

## 書き出しの仕組み

FFmpeg.wasm は 1 スレッドの WASM でソフトウェアエンコードするため、縦 1080×1920 の 4 分の曲で数十分かかり、動画全体をメモリに載せる必要があります。
そこで本アプリはブラウザ標準の **WebCodecs（ハードウェアエンコード）** を使っています。

- 映像：元動画を `VideoDecoder` でデコード → Canvas で字幕を合成 → `VideoEncoder` で H.264 にエンコード。**各フレームのタイムスタンプは元動画の表示時刻をそのまま使う**ため、可変フレームレート（iPhone）でもズレません。回転メタデータ（iPhone の縦動画）は焼き込んで正立させます。
- 音声：AAC は**再エンコードせず元のデータをタイムスタンプごとコピー**（音質劣化・音ズレなし）。AAC 以外は AAC に変換。
- 字幕：プレビューと同じ CSS（`writing-mode: vertical-rl`、縦中横、約物の縦組み）を SVG foreignObject で実解像度にラスタライズして合成するため、プレビューと同じ見た目になります。
- 大きな動画：動画はメモリに読み込まず必要な部分だけ読みます。「先に保存先を選んで直接書き込む」を使うと出力もディスクへ直接書き込みます。
- WebCodecs でデコードできないコーデックの場合は、`<video>` を等速再生してフレームを取得する方式に自動で切り替えます（実時間かかります）。

## テスト

- `http://localhost:5173/tools/selftest.html` … 自動セルフテスト（タイミング計算などの単体テストと、縦 9:16（回転メタデータ付き）・縦書き・横 16:9・正方形・4K・HEVC の各動画で書き出しを行い、解像度・音声タイミング・映像タイミング・字幕の表示区間を検証）
- `http://localhost:5173/tools/make-test-video.html` … 毎秒ちょうどにビープ音と白フラッシュが入った検証用動画を生成

## 既知の制限

- Safari / Firefox は WebCodecs・File System Access API の対応が不十分なため非推奨です。
- iPhone の HDR（Dolby Vision / HLG）動画は SDR に変換して書き出されるため、色味が元動画と多少異なることがあります。
- 書き出しは H.264 + AAC 固定です（HEVC 出力は未対応）。
- ASS 書き出しの縦書きは表示ソフトによって再現度が異なります（焼き込み MP4 は正確に縦書きされます）。
